# AGENTS.md

JARVIS-IA / "Nia": desktop voice AI assistant (Google Gemini Live + PyQt6/tkinter UI, PNGtuber avatar, 80+ tools). **All user-facing output is Argentine Spanish** — persona in `core/prompt.txt`, tool messages, logs, and commit messages. Never "fix" the Spanish or the persona (e.g. Nia must never use parentheses for emotion; never delete user files without confirmation).

## Run & verify

- Launch (background, survives terminal close): `./run_jarvis.sh` → logs in `logs/nia_run.log`.
- Foreground: `.venv/bin/python main.py` (Python 3.14.5 venv; **must run from repo root**).
- Quick regression after touching actions/main.py: `.venv/bin/python tests/smoke_tools.py` (imports every `actions` module incl. `.pyc`-only, checks the `fn(parameters, player, speak)->str` convention, runs safe dry-runs, validates `agent/tool_schemas.json`). Exit 0 = OK; `gesture_engine` WARN is expected (helper lib, not an action). Baseline: 156 actions + 19 pyc-only, FAIL 0, schema 119 tools.
- Single-instance `fcntl` flock at `/tmp/.jarvis_single_instance.lock` (main.py:4798): a second instance exits silently. To restart, kill the running process; deleting the lock file does NOT release the held flock and allows a duplicate.
- Requires `config/api_keys.json` (`gemini_api_key`; gitignored — template: `config/api_keys.example.json`). Missing key → setup dialog at startup. Offline STT needs `config/vosk_model/` (gitignored; `download_vosk.py` fetches it).
- There are **no tests, no linter, no CI** (README's `tests/smoke_tools.py` exists and is the regression harness; `nia_watchdog.sh` doesn't). Verify by importing modules (`python -c "import actions.xxx"`), running `tests/smoke_tools.py` (exit 0 = OK), or running the app.
- Self-healing loop: `self_improve(action="heal", tool=..., error=..., apply="SÍ autorizo")` asks DeepSeek (OpenRouter) for a minimal patch, verifies it on a copy (`py_compile` + import + signature check, up to 3 attempts), then applies with a backup in `backups/` and auto-rolls-back if the real file fails to compile. Safety deny-list: `self_edit`, `self_improve`, `learning`, `auto_programmer`, `main`. Without `apply`, it only proposes the patch and waits for user confirmation ("SÍ autorizo"). This pairs with `actions/learning.py` (records 2+ failures as `training.fallo_*` lessons) as the trigger.
- Tools on demand (tier CAAL/OpenClaw): `skill_creator(action="create", name, description, instructions)` generates the Python module for a tool via DeepSeek (OpenRouter, `_ask_llm`), validates it (name regex + `tool_creator._validate_code` safety patterns + signature `def <name>(parameters, player=None) -> str`), then registers through `auto_programmer` (compile + sandbox dry-run + `custom_tools.json` + in-memory injection + forced reconnect). `action="list"` shows fabricated tools. Fabricated tools are pure-logic stdlib only (no file/network/subprocess — enforced), dispatched automatically by a `_execute_tool` fallback that does `importlib.import_module("actions.<name>")` + getattr + signature-aware call. Working example: `cuenta_dias`.
- Screen perception: `screen_pointer` (cursor/window/zone under pointer) and `describe_screen` ("Mirá lo que veo" — full-screen capture + Gemini description; zone=screen|cursor|window) both reuse `real_vision._call_gemini_vision`, which now retries models with backoff on 429/5xx. Screenshots land in `~/NiaSandbox/captures/`.
- Ambient context per turn (style AYO/Samuel): `actions/ambient_context.py` injects `[CONTEXTO AMBIENTAL]` (active window + time + clipboard preview, 100% local) into the live session at the start of a user turn. `main._mic_callback` triggers `_schedule_ambient_injection()` on the first VAD crossing of a turn (`turn_complete=False` to merge with the audio) and re-arms during silence. Also a tool `ambient_context_action` (`raw=1` → dict).
- Adaptive proactivity (style Loyca/ContextAgent): `actions/proactive_action.py` `decide_proactive(last_user_speech)` scores local signals — `repeated_failures` (from `training.fallo_*` in long_term), `window_stuck`, `system_stress` (psutil), `idle_long`, `system_anomaly` (statistical deviation vs per-hour baseline) — weighted by persistent `memory/proactive_weights.json`, only speaks above threshold, respects a 20-min cooldown and never interrupts a conversation <2 min. `give_feedback(signal, useful)` adjusts weights; `mark_user_engaged()` (called on the next user turn <90s after an emission) reinforces positively, and an emission with no reaction in 8 min decays the signal. `main._proactive_monitor` uses it (sends `[SUGERENCIA PROACTIVA]` turns); tool actions `decide`/`feedback`/`status` also exposed to Nia.
- Anomaly detection 2σ (style Cryp): `actions/anomaly_monitor.py` learns "lo normal" per hour of the day (CPU/RAM/top process, rolling window, persisted in `memory/anomaly_hourly.json`) and flags when a reading deviates >2.2σ from its own baseline AND exceeds an absolute floor AND the previous sample was already elevated (sustained, not a spike). `main._proactive_monitor` calls `record_sample()` every tick so the baseline accumulates even while cooldown blocks speech; `detect_anomaly()` feeds decide_proactive as the `system_anomaly` signal (weight 1.2). Tool `anomaly_monitor` actions: `detect` | `status` | `reset`.
- Nightly maintenance ("Neuro-sleep"): `actions/nightly_maintenance.py`. In the 02:00–06:00 window (checked cheaply each `_proactive_monitor` tick, once/day, daemon thread) Nia runs the full `tests/smoke_tools.py` regression, diagnoses broken tools (`training.fallo_*` → tool names), zips a project backup (`.py/.json/.md/...` excluding `.venv/caches/logs/backups`, once daily name `nia_maintenance_<date>.zip`), and cleans `~/NiaSandbox/captures` older than 7 days. Reports land in `memory/maintenance_report.json` + `.md` (greppable by `morning_brief`). Tool `nightly_maintenance` actions: `run` (force now), `report`, `status`. State in `memory/maintenance_state.json`.
- Episodic memory with receipts (style Magi): `actions/episodic_memory.py`. Saving a fact (`save`) stores it WITH provenance — `receipt.quote` (literal quote of where it was said), `cuando` (timestamp), `session` — so Nia can show the source on "¿de dónde lo sabés?" (`source` action). `recall` ranks by token overlap; `revoke(id)` removes the episode AND leaves a tombstone in `memory/episodes.json` (Nia warns "antes revocaste algo parecido" if it tries to re-learn a revoked fact). Episodes with `importance>=3` auto-sync into the long-term prompt memory (`long_term.json`/`episodes`). Persisted in `memory/episodes.json` (own file so prompt-memory trimming can't destroy receipts).
- Boot/day refresh loop: `morning_brief` (auto 6:00–12:00 once/day + on demand) reads the `training` category of `long_term.json`, reports new `corrección_*` lessons and broken `fallo_*` tools, spawns ≤2 background workers that cold-prepare a verified fix per broken tool (only `actions/*.py` sources; skips pyc-only/deny-list), announcing "decí SÍ autorizo" over voice when ready — and opens with the last-session summary from `context.conversación_*` ("retomar el hilo"). Main's `_summarize_now_blocking`/`_summarize_worker` (main.py:3706) already writes those summaries on shutdown via `ui._win._on_shutdown_hook`.
- Text input bar (modo escritura): `_NiaTypeBar` (QLineEdit heredado, clase en `ui.py`) se muestra con click en el botón ⌨ del header (o con Ctrl+E si lo agregás) — Enter envía, Esc oculta. El texto escrito entra por el mismo canal que la voz: `_on_text_command` (main.py:3960) hace `write_log("⌨️ Tú: …")`, append a `_conversation_context`, `_fire_phrase_triggers()`, y envía `session.send_client_content(turns={...}, turn_complete=True)`. ## `.pyc`-only modules (critical)

`sitecustomize.py` installs a sourceless importer so `.pyc` files are importable without `.py` sources. It only loads because scripts run from repo root — always run from repo root.

These modules have **no `.py` source; behavior lives in committed Python 3.14 bytecode** (matches `.venv`):
`actions/{daily_summary, desktop_kb, dev_agent, file_processor, game_kb, game_updater, mouse_kb, mouse_keyboard, obs_control, obsidian_bridge, recall_memory, rgb_control, screen_capture, _self_agent_core, send_message, tts_local, usage_stats, web_kb, youtube_kb}` and `memory/semantic_memory`. `actions/self_agent.py` (source) imports the pyc-only `_self_agent_core`.

To change one of these: write a `.py` with the same module name (source takes precedence over `.pyc`; keep/delete the old `.pyc`), or recompile a new `.pyc` for 3.14. Don't delete `sitecustomize.py`.

Some action `.py` files are intentional "NOT IMPLEMENTED" stubs (`arca_invoice`, `flight_finder`, `gmail_control`, `google_calendar`, `google_drive`, `google_maps`, `smart_home`, `social_media`, `tiktok_analyzer`) so Nia doesn't fabricate results — not bugs. (Note: `git_control`, `knowledge_base`, `image_generation` and `codebase` were once stubs but ARE implemented now: git status/diff/commit, Obsidian semantic/TF-IDF search, free Pollinations image gen, and a local codebase analyzer with `index`/`info`/`search`/`find_symbol`/`generate_docs`/`list`/`remove` persisting to `memory/codebase_index/`.)

## Architecture

- `main.py` (~5k lines): Live loop/reconnect, tool dispatch in `JarvisLive._execute_tool` (main.py:3400), tool schemas in `TOOL_DECLARATIONS` (main.py:692).
- `actions/`: tool modules, convention `fn(parameters: dict, player=None, speak=None) -> str`. `player` is the `JarvisUI` (`ui.py`) — has `.write_log()`, `.set_state()`, `.muted`.
- `ui.py` (~2.4k lines): `JarvisUI` + glassmorphic PyQt6 window + `assets/sphere.html` (WebEngine orb). Callbacks `on_text_command` (texto escrito), `on_stop_command`, `on_config_saved`, `on_typing_mode` (UI → main). `gpu_acceleration` in `api_keys.json` toggles the Chromium flags set at the top of main.py (affects rendering/RAM).
- `agent/`: subagent system (researcher/coder/organizer/computer), configured in `config/subagents.json` (OpenRouter or Gemini backends). Subagent tool schemas live in `agent/tool_schemas.json`, regenerated with `python agent/sync_tool_schemas.py` from the whitelists in `agent/subagents.py` (`_TOOLS`) + `TOOL_DECLARATIONS` in main.py + the 3 internals in `agent/toolbox.py` (`current_time`, `remember_info`, `recall_memory`). Run the sync whenever you change a tool's schema/whitelist. `agent/toolbox.py` resolves calls by name: internal → `TOOL_ACTIONS` map (exceptions like `weather_action`) → **dynamic `actions/<name>.<name>` import** for anything present in the schema.
- `pngtuber/`: separate avatar process; main.py talks to it over TCP 127.0.0.1:8791 (`pngtuber/client.py`).
- `beta_config.py`: pro-tool gating, currently everything allowed/unlimited.
